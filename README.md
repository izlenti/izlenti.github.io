# MOVIQ - Yapay Zeka Destekli Film & Dizi Rehberi

![MOVIQ](https://img.shields.io/badge/MOVIQ-AI%20Cinema%20Guide-00bcd4?style=for-the-badge)

MOVIQ, global film/dizi verilerini gerçek zamanlı analiz ederek size akıllı öneriler sunan bir sinema rehberidir.

## 🚀 Özellikler

- **Yapay Zeka Analizi:** Puanlama, oy sayısı, bütçe-hasılat dengesi analizi
- **Kategorize Keşif:** Trend, Korku, Komedi, Bilim Kurgu, 90'lar ve daha fazlası
- **Gerçek Zamanlı Veriler:** TMDB API ile sürekli güncellenen içerik
- **Platform Bilgisi:** Türkiye'de nerede izlenir (Netflix, Amazon, vb.)
- **Dış Linkler:** IMDb, Rotten Tomatoes, Ekşi Sözlük entegrasyonu

## 🛠 Teknolojiler

- React + Vite
- Tailwind CSS
- TMDB API
